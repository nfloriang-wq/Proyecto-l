Cómo clonar:
El coordinador del grupo creo el proyecto, lo enlazo a un repositorio de Github y nosotros los integrantes tuvimos que clonarlo a excepción del coordinador para poder tener el proyecto en nuestro eclipse tal y como el lo creo, esto lo hicimos mediante la terminal de git bash here, aplicando el comando de git clone y el url del repositorio.
JDK:
Para la elaboración del proyecto utilizamos la versión de JDK 11 para no tener ningún problema de compatibilidad a la hora de ir avanzando en el proyecto.
Como ejecutar:
Nuestro proyecto tiene una pantalla principal la cual contiene 3 apartados: Iniciamos en el apartado de materiales para poder revisar los libros o revistas que se han ingresado y también podemos añadir y eliminar los materiales que ya no se necesiten, en este apartado se necesita ingresar un código, un título, un autor, año y cantidad de copias, mientras que en revista solo se necesita el código y el título, si no se ingresa nada en los apartados mostrara una ventana que diga que se ingresen sus respectivos datos. 
En el segundo apartado tenemos a los usuarios en este podemos revisar los usuarios ingresados y cuantos libros tienen prestados, también podemos registrar nuevos usuarios, ya sean tanto docentes como estudiantes, este apartado funcionara si se colocan los datos necesarios, ya que se necesita un carnet y el nombre del usuario junto a su puesto, indicando si es docente o estudiante.
En el tercer apartado tenemos los préstamos, en este apartado podemos prestar y devolver el material que el usuario indique y también tenemos el historial de los libros que se han prestado, en este para prestar un libro se necesitara el carnet del usuario y el código del material sino no se podrá prestar, y para devolverlo se necesitara el código del material únicamente.

Decisiones de diseño:
Principalmente se había pensado tener una interfaz con 5 opciones para el proyecto pero tras la revisión de la primer semana junto a decisiones a lo largo del proyecto nos decidimos por tener nada más 3 apartados ya que no necesitábamos una interfaz tan avanzada o profesional para el proyecto ya que nos tomaría posiblemente más tiempo por lo que no nos convendría, los 5 apartados tendrían que haber sido los siguientes: Inventario, Prestamos, Usuario, Prestamos activos y Devoluciones, mientras que al final con los 3 apartados logramos tener únicamente el apartado de Material en este se podía revisar los materiales ingresados y podemos ingresar conforme necesitemos, en el apartado de Usuario podemos ingresar a los usuarios y tener control de los prestamos activos y en el apartado de Prestamos podemos prestar como devolver material, lo hicimos así para poder tener algo más simple y pequeño pero igual de funcional para cada uno de nuestros usuarios.
